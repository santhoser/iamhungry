## Architecture and key files

- React/TypeScript/Vite frontend, Express/SQLite local API with Node built-in node:sqlite (Node >=22.13), plus Workers/D1 backend. Local data lives in ignored `data/`; settings in `config/restaurant.json`. Workers settings, uploads and rate limits persist in D1; uploaded images ≤2 MiB, chunked at 256 KiB. Seed images are static assets.
- `shared/domain.ts`: types, permissions-related roles/statuses, tax math, QR builder. `shared/counter-items.ts`, `shared/menu-history.ts`: shared validation/history helpers.
- `server/db.ts`: local schema, compatibility upgrades, catalogue seed, transactions, scrypt passwords and configuration. Local compatibility upgrades preserve preexisting databases; D1 uses the deployed baseline plus additive migrations.
- `server/app.ts`, `workers/app.ts`: API, validation, auth/roles, orders/payment/reporting/uploads. Workers guarded atomic batches retry conflicts; batched reads/inserts keep 100-line checkout/current-order reads within the free invocation query budget.
- `server/index.ts`: local startup and Vite middleware/HMR on the same server. `workers/crypto.ts`: salted versioned PBKDF2-SHA256 (100,000 iterations). Sessions in both runtimes are random, hashed in storage, expire after eight hours, HttpOnly/SameSite Strict and Secure on HTTPS. Same-origin writes and rate limits enforced.
- `src/App.tsx`: customer menu/cart/tracking/receipt. `src/Admin.tsx`: staff screens/editors. `src/ConfirmDialog.tsx`: accessible app confirmation. `src/TaxLines.tsx`: split-tax lines and historical fallback. `src/styles.css`: theme, mobile/print layouts.
- `wrangler.jsonc`: staging-only configuration; existing database binding retained after its authorized full schema/data reset. `scripts/wrangler-local.mjs`: Windows-compatible launcher with workerd copied into ignored `data/tools/`.
- `tests/`: local/domain/API, catalogue parity, Workers contracts/concurrency/workerd and desktop/mobile browser flows. Browser fixtures use isolated databases and test accounts; never reuse fixture credentials for restaurant accounts.
